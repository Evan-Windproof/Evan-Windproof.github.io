从一个小片段开始

学习笔记可以先记录问题，再记录代码与观察。以下均为排版示例。

C

#include <stdio.h>
int main(void) { puts("Hello"); return 0; }

C++

#include <iostream>
int main() { std::cout << "Hello\n"; }

Rust

fn main() { println!("Hello"); }

Python

print("Hello")

Shell

printf '%s\n' 'Hello'
