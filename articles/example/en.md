## A static reading space

Articles are served from local Markdown files. Read them in **Aelthoren** and use Back, Forward and Reload to navigate.

### Basic formatting

- **Bold** and *italic* text
- `Inline code`
- Headings, paragraphs, quotes and lists
- A safe [GitHub link](https://github.com/Evan-Windproof/Evan-Windproof.github.io)

### Code example

This snippet is only a code block demonstration:

```javascript
const message = 'Hello, Evavind!';

```

## Publishing another article

1. Choose a stable article ID.
2. Add Chinese and English Markdown files.
3. Register title, date, category, summary and file paths in `articles/index.js`.

---

Raw HTML is displayed as text and never executed. This small reader does not support every Markdown extension.
