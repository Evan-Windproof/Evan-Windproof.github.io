## 一个静态的阅读空间

文章由本地 Markdown 文件提供。你可以在 **Aelthoren** 中阅读，并使用返回、前进和刷新按钮。

### 支持的基本格式

- **粗体**与 *斜体*
- `行内代码`
- 标题、段落、引用和列表
- 安全的 [GitHub 链接](https://github.com/Evan-Windproof/Evan-Windproof.github.io)

### 代码示例

下面只是用于演示代码块的示例：

```javascript
const message = 'Hello, Evavind!';
console.log(message);
```

## 发布下一篇文章

1. 为文章选择一个稳定的 ID。
2. 添加中文和英文 Markdown 文件。
3. 在 `articles/index.js` 中登记标题、日期、分类、摘要和文件路径。

---

原始 HTML 会作为文本显示，不会执行。这个精简阅读器不支持所有 Markdown 扩展语法。
